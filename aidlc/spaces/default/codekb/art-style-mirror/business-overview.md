# Business Overview

## 목적

art-style-mirror는 어떤 이미지(일반 사진, 직접 그린 그림, 완성된 그림, 연필 스케치)를 넣으면 닮은 화가·화풍 Top 3를 찾고, 왜 닮았는지 색과 선으로 설명하는 로컬 Gradio 앱이다. 4명 팀이 2주 안에 MVP를 만들어 GitHub에 공개하는 것이 목표이며, 최종 산출물은 실행 가능한 코드와 README다(`docs/plan.md` 1장).

한 줄 피치: "두 개의 눈으로 보고, 신뢰도로 고른다" — CLIP은 소재·분위기·양식을, OpenCV는 색·선 수치를 보고, 두 관점의 확률을 합친 신뢰도 순으로 Top 3를 정한다.

## 사용자와 사용 맥락

- 사용자: 자기 그림이나 사진이 어떤 화가와 닮았는지 궁금한 일반 사용자(로컬 실행, `127.0.0.1:7860`)
- 용도: **비상업 학습·연구용** — WikiArt(`huggan/wikiart`)와 Kaggle `artists.csv`(CC BY-NC-SA 3.0) 조건 때문(README "데이터 출처와 이용 조건")
- 결과 해석 한계: 화면과 카드 끝에 "픽셀 수치 기반의 통계적 해석이며 미술사적 평가가 아닙니다."를 항상 붙인다(`explain.DISCLAIMER`)

## 업무 규칙 (코드·문서에서 확인된 것)

- 최종 순위는 항상 `fuse()` 결과만 쓴다. 두 관점이 엇갈리면 숨기지 않고 함께 보여준다(`render_card`의 "분위기는 …, 색감·선은 …").
- 화이트밸런스는 사용자 입력에만 적용하고 명화에는 크기 맞추기만 한다.
- 명화와 사용자 입력은 같은 CLIP 모델 버전으로 변환한다.
- 데이터 분할 70/15/15: 프로필·분류기는 학습셋, 온도 T·가중치 w·등급 경계값은 검증셋, 테스트셋은 최종 평가(#26)에서 한 번만.
- 신뢰 등급 "낮음"이면 Top 3 대신 CLIP·OpenCV 결과를 따로 보여준다.
- 정확도·수치는 실제 실행 결과만 기록한다. 현재 저장소에는 측정된 수치가 하나도 없다.
