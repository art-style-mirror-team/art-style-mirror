## 입력 및 기존 계약

- 입력은 RGB `np.ndarray` (`uint8`, `(H, W, 3)`)이며, 파이프라인에서는 `preprocess_input()` 이후의 이미지를 사용한다.
- 함수명, 인자, 반환 형식은 유지한다.
- `extract_features()`는 계약의 11개 키를 계속 반환한다. 이번 이슈는 색 특징만 실제 계산하고, 선 특징 5개는 현재 스텁 값을 유지한다.
- `palette`는 RGB 순서의 정수 채널값(각 0–255)으로 5개 색을 반환한다. 수치 비교 대상에서는 계속 제외한다.

## 제안 측정 방식

| 특징 | 제안 정의 | 범위·해석 |
| --- | --- | --- |
| `brightness` | RGB를 OpenCV의 RGB→grayscale 변환으로 휘도 이미지로 바꾼 뒤 픽셀 평균을 255로 나눈다. | 0–1, 낮을수록 어둡다. |
| `contrast` | 같은 휘도 이미지의 표준편차를 127.5로 나눈다. | 0–1, 낮을수록 휘도 분포가 균일하다. |
| `saturation` | RGB→HSV 변환 후 S 채널 평균을 255로 나눈다. | 0–1, 낮을수록 무채색에 가깝다. |
| `warmth` | 픽셀마다 `(R - B) / 255`를 계산해 평균을 구하고, `(평균 + 1) / 2`로 변환한다. | 0–1, 0.5는 중립, 0.5보다 크면 따뜻한 색, 작으면 차가운 색 쪽이다. |
| `color_diversity` | 지각적 색 차이를 고려해 Lab 색공간에서 5개 대표색으로 군집화하고, 군집별 픽셀 비율의 Shannon entropy를 `log(5)`로 나눈다. | 0–1, 한 색에 몰릴수록 낮고 5개 군집의 비율이 고를수록 높다. |
| `palette` | 동일한 Lab 군집의 중심을 RGB로 변환해 군집 크기 내림차순으로 반환한다. | RGB 정수 배열 5개. 실제 고유색이 5개보다 적으면 가장 큰 군집 색을 반복해 길이 5를 맞춘다. |

색 군집화는 재현성을 위해 고정된 시드의 MiniBatch K-Means를 사용하고, 입력이 큰 경우 고정 간격으로 최대 10,000픽셀을 표본으로 뽑는 방안을 제안한다. 팔레트와 다양성은 같은 군집 결과를 공유해 서로 다른 색 분할 기준이 생기지 않게 한다.

## 흑백 처리

- `is_grayscale()`의 현재 기준인 픽셀별 RGB 최대값과 최소값 차이의 평균 `< 8.0`을 유지한다. 입력 채널 순서는 계약대로 RGB다.
- `gray=True`일 때 `brightness`와 `contrast`는 흑백 휘도에서 계속 계산한다. 색 정보가 없다는 뜻으로 `saturation=0.0`, `color_diversity=0.0`, `warmth=0.5`(중립)로 반환한다.
- `gray=True`의 `palette`도 동일한 5색 계약을 유지하며 각 색의 R, G, B가 같은 회색조로 만든다.
- 흑백 이미지는 `predict_cv(gray=True)`에서 선 특징만 사용하므로, 반환되는 색 특징은 형식과 설명용으로 보존하고 순위에 반영하지 않는다.

## 범위 경계 및 검증

- `edge_density`, `direction`, `straight_ratio`, `roughness`, `stroke_length` 계산과 프로필·판정 로직은 변경하지 않는다.
- 동작 검증 기준: 어두운 이미지와 밝은 이미지의 밝기 순서, 균일 휘도와 큰 휘도 변화의 대비 순서, 무채색의 채도·다양성·중립 온도, 팔레트 5개 및 RGB 범위, 기존 11개 키와 스케치 경로의 호환성.
