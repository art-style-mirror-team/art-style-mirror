## 다른 역할과 맞춘 결정

- **CLIP 모델은 상수 하나로 정한다** (PR #56 리뷰, 이슈 #5 댓글, 2026-11-26). PR #58에서 `CLIP_MODEL_NAME` = `openai/clip-vit-base-patch32`로 정했고, `build_index.py`(#4)도 같은 값을 쓰며 색인 쪽은 `clip_model.txt`로 확인한다. B의 `detect_type()`은 이 모델을 `embed_image()`·`embed_text()`를 통해 그대로 쓴다.
- **`embed_text()`는 받은 문장을 그대로 임베딩한다** (같은 출처, PR #58에서 B가 확인). 안에서 `"a photo of {}"` 같은 틀을 붙이지 않는다. B는 완성된 영어 문장을 넘기므로, 틀이 붙으면 유형 판별이 photo 쪽으로 쏠린다. `clip_keywords()`(#6)에 틀이 필요하면 그 함수 안에서 붙인 뒤 넘긴다.
- **분할은 다시 하지 않고, 중복을 감안해 평가한다** (D 결정, 2026-11-27, 이슈 #3 댓글).
  - 이유: 검증셋 1,035장 중 26장(2.5%)만 학습셋 작품과 코사인 0.95 이상이고(0.99 이상 1장), #9 kNN에서 26장을 빼도 Top-1이 0.706 → 0.700(참고값, PR #59 리뷰)이었다. 다시 분할하면 `meta.csv`의 split이 바뀌어 진행 중인 #8·#9·#13과 C의 작품 기록을 다시 해야 한다.
  - 중복 목록: A가 학습셋과 코사인 0.95 이상인 검증셋 작품 id 목록을 A의 스크립트로 만들어 `artifacts/`에 둔다(파일 이름은 A가 정한다. 예: `near_duplicates.csv`, 열 `id`, `split`, `train_id`, `sim`). 계약 함수는 바꾸지 않는다. 0.95는 `similar_works()`의 `NEAR_DUPLICATE`와 같은 값이다.
  - 검증셋으로 낸 수치(#9~#15의 정확도·ECE, #27)는 "중복 포함"과 "중복 제외"를 둘 다 적는다.
  - #24 등급 경계는 중복을 뺀 검증셋으로 정한다. 중복은 `max_sim`이 0.95 이상으로 튀어 경계를 끌어올린다.
  - 테스트셋 중복 목록은 #26 최종 평가 때 같은 기준으로 처음 만들고, 제외 수치를 같이 낸다. 그 전에는 테스트셋을 열지 않는다(규칙 6).
- **`load_artist_info()`가 계약에 들어갔다** (#71, PR #72 머지, 2026-11-28). PR #67의 형식(`{artist: {"years", "nationality", "intro"}}`, 파일이 없으면 `{}`) 그대로다. 이제 이름·반환 형식을 바꾸려면 계약 변경 이슈를 거친다. 이견이 있으면 #71에 댓글로 남긴다.

## 다른 역할의 변경 중 A에 영향을 주는 것

- **분할은 다시 하지 않는다** (D 결정, 이슈 #3 댓글). `meta.csv`의 `split`을 유지하고, 같은 작품의 사본이 다른 split에 있는 경우는 목록(`near_duplicates.csv`)으로 제외해 평가한다. 기준 0.95는 `similar_works()`의 `NEAR_DUPLICATE`와 같은 값이다.

- **B의 PR #56(#8)은 2026-11-28 머지됐다**(`4af5292`). #8 완료 기준(15장 중 12장)은 B가 #58의 모델로 #8에서 확인한다.

- **명화에는 `features.preprocess_input()`을 쓰지 않는다** (`AGENTS.md` 규칙 9, `contracts/interfaces.md` 공통 규칙). PR #42 이후 이 함수는 종이 자르기와 화이트밸런스까지 한다. `build_index.py`(#4)에서 명화는 RGB로 바꾸고 크기만 맞춘다. 화이트밸런스를 하면 화가 고유의 색이 지워진다.
- **`direction` 특징의 정의가 바뀌었다** (PR #44 리뷰, C·D 합의). 평균 각도(0~180)가 아니라 방향 일관성(0~1)이며, 이미지를 회전해도 값이 같다. #27 변형 안정성 측정에서 회전 변형의 OpenCV 쪽 결과를 해석할 때 감안한다.
