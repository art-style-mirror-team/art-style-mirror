## 다른 역할과 맞춘 결정

- **CLIP 모델은 #5에서 상수 하나로 정한다** (PR #56 리뷰, 이슈 #5 댓글, 2026-11-26). 아직 어디에도 모델 ID가 정해져 있지 않다. `data.py`에 상수로 두고 `build_index.py`(#4)도 같은 값을 쓴다. PR #5 본문에 고른 모델과 이유를 적는다. B의 `detect_type()`은 이 모델을 `embed_image()`·`embed_text()`를 통해 그대로 쓴다.
