## 다른 역할과 맞춘 결정

- **`direction`은 방향 일관성(0~1)이다** (PR #44 리뷰, C·D 합의안 A).
  - 정의: 윤곽선 픽셀 기울기 방향의 2배각을 세기로 가중 평균한 벡터의 길이. 지금 코드의 `np.hypot(cos_mean, sin_mean)`이다. 윤곽선이 없으면 0.0.
  - 이유: 평균 각도는 0과 180이 같은 방향인데 숫자로는 정반대라(±3도 기운 선이 0.015와 0.985), 프로필 평균·표준편차와 z값 비교가 틀어진다.
  - 알려진 한계: 수평선과 수직선이 반씩인 격자(몬드리안)는 서로 상쇄돼 0에 가깝게 나온다. 몬드리안과 고흐의 구별은 `straight_ratio`가 맡는다. 설계 문서에 한계로 적는다.
  - D의 레이더 차트는 PR #46에서 이 정의에 맞췄다(`/180` 제거). PR #44와 PR #46은 비슷한 시점에 머지한다.
- **수치 특징 10개는 모두 0~1이다.** D의 레이더 차트와 `compare()`가 이 범위를 가정한다. 값의 범위나 의미를 바꾸려면 D에게 먼저 알린다.

## PR #42 (#16) 남은 작업

- **유지:** 종이 자르기와 화이트밸런스를 분리한 구조. 종이가 꽉 찬 스케치가 보정되는 것은 이 덕분이다.
- **바꿀 것:** 화이트밸런스를 할지 정하는 조건. 지금 조건(밝기 상위 40% 중 채도 115 이하가 20% 이상)은 연한 색 그림까지 종이로 보고 회색으로 만든다. 안개 풍경, 파스텔, 저녁 하늘이 전처리 후 흑백으로 판정된다. D가 댓글로 준 `wb_v2`의 판정 조건도 같은 문제가 있으므로 그 조건은 쓰지 않는다.
- **방향:** 밝은 영역의 색이 고른지(Lab a·b 표준편차)를 조건에 추가한다. 합성 이미지에서 종이 바탕은 약 2.6, 여러 색이 섞인 연한 그림은 5.5~6.7이었다. 거의 한 색인 그림(안개 풍경 3.94)은 여전히 종이와 가까워 구별되지 않으며, 설계 문서에 한계로 적는다.
- **기준값:** 합성 이미지 값(비율 35%, 편차 4.0)은 임시값이다. 실제 휴대폰 사진(노란 조명·형광등 아래 스케치)과 연한 색 명화로 정하고 표로 PR 본문에 적는다. 명화는 검증셋에서 고른다(`AGENTS.md` 규칙 6). A의 분할 전이면 쓴 작품 이름을 기록한다. 원본 사진은 커밋하지 않는다.
- 보정 배율 상한(지금 1.8)은 실제 사진에서 필요한 최대 배율을 보고 정한다.
- 테스트: 여러 색이 섞인 연한 그림은 흑백이 되지 않음, 노란 조명 음영 스케치는 흑백이 됨, 원래 있던 `[100, 110, 120]` 단색 테스트를 원래대로 되돌림.
- `tests/test_smoke.py`에서 지운 `test_preprocess_and_grayscale`을 되돌린다. 동작 테스트만 `tests/test_features.py`에 둔다.
- `app.py`는 전처리 **후** 이미지로 `is_grayscale()`을 판정한다. 화이트밸런스 결과가 스케치 인식을 좌우한다.

## PR #44 (#18) 남은 작업

- OpenCV 5.1의 `cv2.HoughLinesP`는 `(N, 4)`를 돌려준다. `segments[:, 0]` 대신 `segments.reshape(-1, 4)`를 쓴다. 이것 때문에 pytest 9개가 실패했다.
- `direction`을 위 정의(방향 일관성)로 바꾸고, docstring과 설계 문서에 적는다. 테스트: 한 방향 평행선은 높음, 흩어진 선은 낮음, ±3도 기운 두 입력은 거의 같은 값.
- **가짜 프로필(`_profiles()`)의 `direction`도 0~1로 바꾼다.** 지금은 평균 20~160, 표준편차 15~40(각도)이라, 바꾸지 않으면 #19 전까지 `predict_cv()` 순위가 이 특징 하나에 끌려가고 레이더의 "1위 화가 평균" 축이 1로 잘린다.
- 브랜치가 PR #43 머지 전 main에서 시작해 `features.py`와 `tests/test_features.py`가 충돌한다. `git merge origin/main`으로 PR #43의 실제 색 특징 코드를 살린 채 합친다.
- 실제 몬드리안·고흐 작품 몇 장의 `straight_ratio`와 `direction`을 표로 적는다(이슈 #18 완료 기준). 합성 이미지 결과는 몬드리안 느낌 0.745, 고흐 느낌 0.077이었다.
